# 開発者向けドキュメント

このリポジトリを開発・メンテナンスする人向けの仕様と取り決めを置く場所です。

## 置き場所のルール

- リポジトリ直下と各パッケージの `README.md` / `README.ja.md` は、パッケージを導入して使う人向けの説明だけを書く(できること、インストール方法、使い方)。
- CI・リリースの流れ、開発の取り決め、仕様、意思決定の記録は、このフォルダに日本語で書く。
